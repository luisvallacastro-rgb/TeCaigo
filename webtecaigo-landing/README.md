# Tecaigo Web

Landing page estatica de Tecaigo.

## Deploy en Render

1. Subir esta carpeta a un repositorio de GitHub.
2. En Render, crear un nuevo **Blueprint** o **Static Site** desde ese repositorio.
3. Render detecta `render.yaml` y publica la raiz del proyecto como sitio estatico.

Configuracion manual equivalente:

- Runtime: Static
- Build command: vacio
- Publish directory: `.`
